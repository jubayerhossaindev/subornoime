## The five principles

1. **Human readability first** — a new developer reads the code without
   hunting for meanings.
2. **Meaningful naming always** — names carry role, domain and unit;
   abbreviations are banned (CI-enforced).
3. **C++20 only** — no post-C++20 features, no compiler extensions.
4. **Original Suborno documentation** — comments describe this codebase;
   third-party provenance is preserved as explicit legal lines.
5. **Consistent engineering standards** — one formatter, one naming standard,
   one test framework, one dependency manager; no duplicates.

## Architecture preservation

The module layout is fixed and layer-checked (`scripts/check-layering.py`):
portable core (`unicode`, `layout-api`, `dictionary`, `spell`, `candidates`,
`persistence`, `settings`, `layouts`, `core`) stays platform-independent;
all Windows/COM/TSF integration lives under `src/platform/windows/`. Layout
definitions and per-keystroke session state remain separate types. Bengali
Unicode behaviour is pinned by the BDS conformance and layout regression
suites; adding new language support (e.g. Assamese) is out of scope by
decision (ADR-0003, bengali-unicode-support.md).
